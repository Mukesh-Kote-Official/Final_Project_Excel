# Final Project Excel Dashboard & Analysis

## Project Overview

This project is an advanced Microsoft Excel analysis dashboard created using formulas, pivot tables, charts, what-if analysis, conditional formatting, and data visualization techniques.

The workbook is designed to analyze business/sales-related datasets and present insights in a professional dashboard format.

# File Information

* **File Name:** Final_Project_Excel.xlsx
* **Tool Used:** Microsoft Excel
* **Project Type:** Data Analysis & Dashboard Project

# Workbook Structure

## Sheets Included

| Sheet Name            | Description                                                 |
| --------------------- | ----------------------------------------------------------- |
| Project Instructions  | Contains project guidelines and tasks                       |
| Final Project Dataset | Main raw dataset used for analysis                          |
| Task_1 to Task_5      | Individual task solutions using Excel formulas and analysis |
| Scenario Summary      | What-If Analysis and scenario management                    |
| Task_6 LR             | Logical/Lookup related analysis                             |

| Task_8 HVC            | High value customer analysis                                |

| Task_11_Abb           | Additional business analysis                                |

| Dashboard             | Interactive dashboard with charts and KPIs                  |
